# 🇱🇰 Sri Lanka Road Network
A data analysis project that maps and validates Sri Lanka’s National Road Network using OpenStreetMap data and official RDA records.

## Current Features
- **Network Analysis**: Fetches and cleans Class AA road data from OpenStreetMap.
- **Validation**: Compares OSM road lengths against official RDA gazetted figures.
- **Junction Detection**: Identifies and classifies intersections as AA–AA or AA–Other.
- **Interactive Map**: Includes an interactive map with filterable layers (road details, junction types, and lane counts).

## Usage
- Install requirements by uncommenting and running first cell of `srilanka_roads.ipynb`.
- Comment out the first cell and run all cells.
